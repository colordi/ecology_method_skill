# 意图对齐问题模板

## 维护说明

本文件提供高信息密度的问题模板，帮助快速识别用户的研究意图。随着使用经验积累，可以：

- **优化问题**：根据实际效果调整问题的表述，使其更清晰、更高效
- **添加新问题**：针对特定研究类型添加专门的问题
- **补充示例**：添加更多典型对话示例，展示如何灵活运用问题
- **调整顺序**：根据重要性和逻辑关系调整问题顺序
- **保持简洁**：避免问题过多，通常3-5个核心问题即可建立清晰的研究上下文

## 问题设计原则

1. **高信息密度**：每个问题应该能获取多个维度的信息
2. **开放但聚焦**：允许用户自由表达，但引导到关键信息
3. **避免专业术语过载**：使用用户容易理解的语言
4. **渐进式深入**：从宏观到具体，逐步细化
5. **灵活调整**：根据用户回答动态调整后续问题

## 核心问题模板

### 第一轮：建立研究背景（2-3个问题）

**问题1：研究对象与目标**
```
请简要描述：
- 你的研究对象是什么？（物种/群落/生态系统/景观）
- 你希望通过这些数据回答什么研究问题？
- 你的研究目标是什么？（描述现状/预测变化/解释机制/指导保护）
```

**问题2：数据概况**
```
关于你手头的数据：
- 数据类型是什么？（物种名录/功能性状/环境因子/遥感影像/分子数据）
- 数据的时空范围如何？（采集时间、地点、样本量）
- 数据是否已经过初步整理？
```

**问题3：研究方向偏好**（可选，根据前两个问题的回答决定是否询问）
```
你倾向于使用什么类型的研究方法？
- 统计分析（相关性、差异性、多元分析）
- 模型模拟（预测模型、机制模型）
- 实验验证（野外实验、受控实验）
- 综合分析（多方法结合）
```

### 第二轮：细化研究方向（1-2个问题）

根据第一轮回答，选择性询问：

**如果研究对象是物种/种群**：
```
- 你关注的是物种多样性格局、种群动态、还是物种间关系？
- 是否涉及特定的功能群或关键物种？
```

**如果研究对象是群落/生态系统**：
```
- 你关注的是结构特征（组成、多样性）还是功能过程（生产力、养分循环）？
- 是否涉及环境梯度或干扰因素？
```

**如果涉及时间维度**：
```
- 你关注的是长期趋势、季节变化、还是事件响应？
- 是否需要考虑气候变化或人为干扰的影响？
```

**如果涉及空间维度**：
```
- 你关注的空间尺度是什么？（局域/景观/区域/全球）
- 是否涉及空间格局、空间过程或尺度效应？
```

## 问题运用策略

### 策略1：快速建立上下文
对于表述清晰的用户，可以将多个问题合并为一个综合性问题：
```
请告诉我：你的研究对象、手头数据的类型和规模、以及你希望回答的核心研究问题。
```

### 策略2：渐进式引导
对于表述模糊的用户，先问最基本的问题，根据回答逐步深入：
```
第一步：你的研究对象是什么？
第二步：（根据回答）你手头有哪些相关数据？
第三步：（根据回答）你希望通过这些数据发现什么？
```

### 策略3：确认式对齐
当用户已经提供了一些信息，用确认式问题快速对齐：
```
根据你的描述，我理解你的研究是关于[研究对象]的[研究问题]，
使用[数据类型]进行[分析方法]。这样理解对吗？有需要补充或修正的吗？
```

## 典型对话示例

### 示例1：物种多样性研究

**用户**："我有一些森林样地的植物调查数据，想发表论文。"

**Claude**："请简要描述：(1) 你的样地分布在哪里，有多少个样地？(2) 调查了哪些信息（物种名录、盖度、高度等）？(3) 你希望探讨什么问题（多样性格局、环境影响、功能性状等）？"

**用户**："20个样地分布在不同海拔，记录了物种名录和盖度，想看海拔对多样性的影响。"

**Claude**："明白了。你是否还收集了环境数据（土壤、气候等）？是否关注特定的多样性维度（物种多样性、功能多样性、系统发育多样性）？"

### 示例2：种群动态研究

**用户**："我监测了一个鸟类种群5年的数据，不知道怎么分析。"

**Claude**："关于你的监测数据：(1) 记录了哪些信息（数量、繁殖成功率、存活率等）？(2) 监测频率如何（每年几次）？(3) 你想探讨种群的长期趋势、年际波动、还是与环境因子的关系？"

### 示例3：生态系统功能研究

**用户**："我有一些草地生态系统的生产力和环境数据。"

**Claude**："请告诉我：(1) 生产力数据是如何测量的（生物量、NDVI等）？(2) 环境数据包括哪些因子（气候、土壤、管理方式等）？(3) 你的研究目标是解释生产力的驱动因素、预测未来变化、还是评估管理效果？"

## 注意事项

1. **避免一次性问太多问题**：通常第一轮2-3个问题即可，根据回答再决定是否需要补充
2. **灵活调整问题顺序**：根据用户的表达习惯和信息完整度调整
3. **及时总结确认**：在获得足够信息后，总结理解并请用户确认
4. **识别隐含信息**：从用户的描述中推断可能的研究方向，但需要确认
5. **保持对话自然**：不要机械地套用模板，根据具体情况灵活表达
