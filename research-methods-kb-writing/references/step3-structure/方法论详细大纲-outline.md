# 生态学研究方法论详细大纲（Methodology Outline）

> **设计原则**：每个一级模块可独立生成；二级标题为核心写作单元；三级标题为可选细节，按研究类型取舍。

---

## 模块 1：Study Design（研究设计）

### 1.1 研究背景与问题定义

#### 1.1.1 研究问题陈述
- 核心科学问题（1–2 句，客观表述）
- 拟检验的假设或预期模式（若适用）

#### 1.1.2 概念框架与变量关系
- 响应变量与解释变量的逻辑关系（可附简图）
- 潜在混杂因素与控制策略

### 1.2 研究系统与对象

#### 1.2.1 研究对象界定
- 目标物种/功能群/群落类型
- 纳入标准与排除标准（如适用）
- 分类学处理规则（同物异名、亚种/变种合并等）

#### 1.2.2 研究区域描述
- 地理位置（经纬度、行政区划、保护区名称等）
- 气候带/生物地理区
- 海拔范围与地形特征

#### 1.2.3 生境类型与异质性
- 主要生境类型划分依据
- 生境异质性描述（若涉及多生境对比）
- 人为干扰梯度（若适用）

### 1.3 时空尺度与采样框架

#### 1.3.1 空间尺度设计
- 研究区总范围（km² 或 ha）
- 样点/样方间距与布设密度
- 空间层级（景观→斑块→样方）

#### 1.3.2 时间尺度设计
- 研究持续时间（年/季/月）
- 采样频次与时间间隔
- 物候/季节窗口选择依据

#### 1.3.3 采样设计类型
- 设计类型：随机 / 分层随机 / 系统 / 梯度 / 区组
- 分层依据（若分层）：生境/海拔/干扰等
- 样本量与统计功效（若有预分析或文献依据）

### 1.4 实验/准实验设计（若适用）

#### 1.4.1 处理与对照设置
- 处理因子与水平定义
- 对照类型（空白/程序对照/参照系统）

#### 1.4.2 随机化与区组
- 随机化方法（完全随机/随机区组/拉丁方等）
- 区组划分依据与区组数量

#### 1.4.3 重复层级定义
- 真实重复 vs. 伪重复的界定
- 空间重复（站点/样方）与时间重复（次数/季节）

## 模块 2：Data Collection & Materials（数据采集与材料）

### 2.1 采样单元规格

#### 2.1.1 样方/样带设计
- 样方形状、面积（m²）或样带长度×宽度（m）
- 嵌套设计说明（若有多尺度嵌套）

#### 2.1.2 设备布设规格
- 设备类型（陷阱/相机/传感器）与型号
- 布设密度、间距、高度/深度
- 工作参数（触发间隔、灵敏度等）

#### 2.1.3 点计数/样线设计（若适用）
- 点计数半径或样线长度
- 停留时间/行进速度
- 重复调查次数

### 2.2 采样力度与有效样本

#### 2.2.1 采样时长与周期
- 单次采样持续时间
- 陷阱日/相机日计算方式

#### 2.2.2 有效样本判定
- 有效样本定义（如独立探测事件的时间阈值）
- 无效/剔除样本处理规则

### 2.3 物种/分类单元记录

#### 2.3.1 记录内容与口径
- 记录类型：出现/丰度/盖度/频度/生物量
- 估测方法（目视估计/网格法/标记重捕等）

#### 2.3.2 鉴定与质量控制
- 鉴定依据（图鉴、检索表、专家鉴定）
- 凭证标本保存（若适用）
- 鉴定一致性控制（培训、校准）

#### 2.3.3 分类学处理规则
- 鉴定精度（种/属/科级）
- 疑难/未定种处理方式
- 形态种编码规则（若涉及）

### 2.4 环境变量/协变量

#### 2.4.1 微生境变量
- 测量项目（温度/湿度/光照/土壤等）
- 仪器型号与精度
- 测量时机/频次

#### 2.4.2 景观/区域变量
- 遥感指数（NDVI/EVI/土地覆盖类型等）
- GIS 派生变量（距离/面积/连接度等）

#### 2.4.3 测量校准与质量控制
- 仪器校准方式
- 重复测量与误差评估

### 2.5 工具与材料清单

#### 2.5.1 野外设备
- 设备名称、型号、主要参数
- 标定/校准方式

#### 2.5.2 软件与版本
- 统计/分析软件（R/Python/SAS 等）及版本号
- 关键包/库及版本号

## 模块 3：Data Processing & Procedure（数据处理与流程）

### 3.1 数据清洗与预处理

#### 3.1.1 分类标准化
- 物种名称标准化流程（同物异名、拼写校正）
- 参照分类系统（如 GBIF Backbone、Catalogue of Life）

#### 3.1.2 去重与独立性处理
- 空间去重规则（空间阈值）
- 时间去重规则（时间阈值）
- 独立探测事件定义

#### 3.1.3 缺失值与异常值处理
- 缺失值识别与处理策略（删除/插补/标记）
- 异常值检测方法与处理规则

#### 3.1.4 单位与量纲统一
- 测量单位标准化
- 量纲转换规则

### 3.2 指标计算

#### 3.2.1 多样性指标
- 物种丰富度（S）
- Shannon-Wiener 指数（H'）、Simpson 指数（D）
- Pielou 均匀度指数（J'）

#### 3.2.2 群落结构指标
- 优势度/稀有种比例
- 功能多样性指标（若适用）
- 谱系多样性指标（若适用）

#### 3.2.3 指标计算口径
- 样本单位（样方/站点/年份）
- 聚合层级与计算公式

### 3.3 数据变换与标准化

#### 3.3.1 丰度/盖度变换
- 变换类型（log1p / sqrt / hellinger / Wisconsin 等）
- 变换理由

#### 3.3.2 环境变量标准化
- 标准化方法（z-score / min-max / range）
- 标准化范围

#### 3.3.3 零值与稀疏性处理
- 稀疏矩阵处理策略
- 零膨胀结构考量

### 3.4 采样完整性评估

#### 3.4.1 物种累积曲线
- 累积曲线类型（样本/个体基）
- 实现方式与置换次数

#### 3.4.2 覆盖度估计
- 覆盖度指标（Sample Coverage）
- 覆盖度标准化阈值

#### 3.4.3 稀释与外推
- 稀释/外推方法（iNEXT / rarefaction 等）
- 标准化到的参照点（样本量/覆盖度）

### 3.5 数据整合与衍生

#### 3.5.1 多源数据整合
- 数据集匹配规则（空间/时间/ID 关联）
- 冲突解决规则

#### 3.5.2 分组与聚合
- 分析单位定义（样方/站点/年份/处理组）
- 聚合统计量（均值/中位数/加和/最大值等）

## 模块 4：Statistical Analysis（统计分析）

### 4.1 分析策略概述

#### 4.1.1 分析目标与问题对应
- 问题 1 → 分析方法 A
- 问题 2 → 分析方法 B
- （按研究问题组织分析模块）

#### 4.1.2 模型选择依据
- 响应变量类型与分布特征
- 数据结构（嵌套/重复测量/空间相关）

### 4.2 群落组成与排序分析

#### 4.2.1 距离度量与变换
- 距离度量选择（Bray-Curtis / Jaccard / UniFrac 等）
- 选择理由

#### 4.2.2 非受限排序
- 方法：PCA / CA / NMDS / t-SNE / UMAP
- 关键参数（维度/迭代次数/收敛准则）

#### 4.2.3 受限排序
- 方法：RDA / CCA / db-RDA
- 解释变量选择与共线性检查
- 置换检验设置

#### 4.2.4 群落差异检验
- PERMANOVA / ANOSIM
- 因子结构与交互项
- 置换策略（置换次数、分层置换）

#### 4.2.5 离散度分析（若适用）
- PERMDISP / betadisper
- 与 PERMANOVA 结果的联合解读

### 4.3 单变量回归/层级模型

#### 4.3.1 模型类型选择
- GLM / GLMM / GAMM
- 分布族与链接函数选择依据

#### 4.3.2 随机效应结构
- 随机截距/随机斜率
- 随机效应因子（站点/区组/年份/个体）

#### 4.3.3 零膨胀与过度离散处理
- 零膨胀模型（ZIP / ZINB）
- 过度离散检测与处理

#### 4.3.4 采样力度标准化
- offset 设置（log 采样力度）
- 或响应变量归一化

### 4.4 模型诊断与稳健性

#### 4.4.1 模型假设检验
- 残差诊断（正态性/同方差性/独立性）
- 模拟残差诊断（DHARMa 等）

#### 4.4.2 共线性检查
- VIF / 相关矩阵
- 共线性变量处理策略

#### 4.4.3 模型比较与选择
- 信息准则（AIC / BIC / WAIC）
- 似然比检验

#### 4.4.4 敏感性与稳健性检验
- 移除极端点/敏感性分析
- 替代模型结构检验

### 4.5 空间/时间结构处理

#### 4.5.1 空间自相关检测
- Moran's I / Mantel 检验
- 变差函数分析（若适用）

#### 4.5.2 空间结构处理
- 空间相关结构（CAR / SAR）
- 空间随机效应
- 阻塞抽样（blocked sampling）

#### 4.5.3 时间序列/重复测量处理
- 自相关结构（AR1 / ARMA）
- 重复测量方差结构

### 4.6 多重比较与假设校正

#### 4.6.1 事后多重比较
- 比较方法（Tukey / Dunnett / Holm 等）
- 比较对象与分组

#### 4.6.2 多重假设校正
- 校正方法（Bonferroni / FDR / Benjamini-Hochberg）
- 应用范围

### 4.7 软件实现与可复现性

#### 4.7.1 统计环境
- 软件与版本（R / Python / JAGS / Stan 等）
- 运行环境（OS / 硬件配置，若相关）

#### 4.7.2 关键包/库
- 包名称与版本号
- 核心函数说明

#### 4.7.3 随机性控制
- 随机种子设置
- 置换/Bootstrap 次数

#### 4.7.4 报告规范
- 显著性水平（α）
- p 值报告精度与范围
- 效应量与置信区间报告

## 使用说明

### 分步生成策略

1. **按模块生成**：每次只生成一个模块（如"模块 1：Study Design"），确保深度与完整性
2. **按二级标题迭代**：若单模块仍过长，可按 `1.1 → 1.2 → 1.3 → ...` 逐节生成
3. **按研究类型裁剪**：并非所有子标题都需要，根据实际研究类型取舍（如无实验设计则跳过 1.4）

### 质量检查点

每个模块生成后，检查：
- [ ] 可复现性：参数、阈值、版本是否明确？
- [ ] 逻辑完整：前后模块衔接是否顺畅？
- [ ] 引用回流：方法选择依据是否有 `[R#]` 占位？
- [ ] 口径一致：变量定义与指标计算口径是否与前文一致？
