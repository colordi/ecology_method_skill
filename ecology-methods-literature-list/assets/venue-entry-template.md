# 发表载体使用建议模板（Venue Entry Template）

> 用途：在 Stage 2（信息检索）筛选候选文献时，记录“期刊/会议/出版平台”的**使用建议**与**风险提示**，帮助你决定：
> - 该载体的文章是否适合作为方法学引用依据
> - 该载体更适合引用“综述/指南/方法比较/实证研究”的哪一类证据
> - 在写作中如何表述与引用（主证据/辅助证据/谨慎引用/不引用）

## [载体名称：期刊/会议/出版平台]

### 1) 载体概况（最小必要信息）
- **类型**：期刊 / 会议 / 出版平台
- **学科与子领域定位**：如（群落生态/保护生物学/生态统计/遥感生态等）
- **出版方/主办方**：
- **官方网站**：
- **同行评审说明（如有）**：单盲/双盲/开放评审/未知

### 2) 推荐用途（核心）
> 这里强调“怎么用”，而非“是否权威”的空泛结论。

- **最推荐引用的文章类型**（勾选/补充）：
  - [ ] 方法学综述（method review）
  - [ ] 方法指南/最佳实践（guideline/best practice）
  - [ ] 方法比较/基准测试（benchmark/comparison）
  - [ ] 软件/工具论文（software/tool paper）
  - [ ] 典型实证应用（applied example）
- **适合作为证据的点**（写 Methods 时可直接对应到“验证点”）：
  1. （例）方法选择理由/适用边界
  2. （例）参数阈值或推荐设置
  3. （例）质量控制与误差来源处理
- **不建议用于支撑的点**（避免误用）：
  - （例）跨系统外推、超出其数据条件的参数结论等

### 3) 引用策略建议（写作落地）
- **在 Methods 中的角色**：主证据 / 辅助证据 / 背景性引用 / 不引用
- **推荐引用方式**：
  - 先引用：综述/指南（若有）
  - 再引用：方法比较/实证应用（与研究系统一致者优先）
- **建议的引用组合**：
  - **最小组合**：1 篇综述/指南 + 1 篇系统匹配的实证/比较
  - **稳健组合**：1 篇经典方法来源 + 1 篇近 10 年综述 + 1 篇系统匹配比较/应用
- **适用时必须补充的信息**（否则不建议引用）：
  - 数据类型/采样设计是否一致：
  - 参数与单位是否可对齐：
  - 是否报告关键限制/前提：

### 4) 风险提示（只记录与你决策相关的信号）
- **潜在风险信号**（如有）：
  - 费用/流程不透明、审稿异常快、编辑部信息不清晰、范围过宽等
- **采取的策略**：
  - [ ] 仅作背景引用
  - [ ] 需要额外交叉验证（至少再找 1 个独立来源）
  - [ ] 不纳入证据链
