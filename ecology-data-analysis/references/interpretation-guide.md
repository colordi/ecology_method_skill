# 结果解释指南

本文档提供常见生态学分析结果的解释框架和要点。

## 多样性指数解释

### Shannon指数 (H')
- **范围**: 通常 0-5，更高表示更高多样性
- **解释要点**:
  - 同时考虑物种丰富度和均匀度
  - H' > 3: 高多样性
  - H' = 1-3: 中等多样性
  - H' < 1: 低多样性
- **生态学意义**: 反映群落的复杂性和稳定性

### Simpson指数 (D 或 1-D)
- **范围**: 0-1（使用1-D时）
- **解释要点**:
  - 值越高表示多样性越高
  - 对优势种更敏感
- **生态学意义**: 反映群落的均匀程度

### 物种丰富度 (S)
- **解释要点**:
  - 最直观的多样性度量
  - 受采样强度影响
  - 需结合物种累积曲线评估

## 统计检验结果解释

### P值解释
- **p < 0.001**: 极显著，用 *** 表示
- **p < 0.01**: 非常显著，用 ** 表示
- **p < 0.05**: 显著，用 * 表示
- **p ≥ 0.05**: 不显著，用 ns 表示

**注意事项**:
- P值不代表效应大小
- 需报告效应量（如Cohen's d, R²）
- 考虑生态学意义，不仅仅是统计显著性

### ANOVA/t检验结果
- **F值或t值**: 检验统计量，值越大表示组间差异越大
- **自由度**: 报告为 df = (组间, 组内)
- **效应量**: 报告 η² 或 Cohen's d
- **解释模板**: "XX处理显著影响YY (F = X.XX, df = X,XX, p < 0.05)，处理组的YY比对照组高XX%"

## 排序分析结果解释

### NMDS (非度量多维尺度分析)
- **Stress值**: 评估排序质量
  - Stress < 0.05: 优秀
  - Stress < 0.10: 良好
  - Stress < 0.20: 可用
  - Stress > 0.20: 不可靠
- **解释要点**:
  - 样点距离反映群落组成相似性
  - 样点聚类表示群落类型
  - 环境向量箭头指向该因子增加的方向

### PERMANOVA 结果
- **R² 值**: 解释变量解释的变异比例（0-1）
  - R² > 0.3: 强效应
  - R² = 0.1-0.3: 中等效应
  - R² < 0.1: 弱效应
- **F值和P值**: 检验组间差异显著性
- **解释模板**: "XX因子显著影响群落组成 (PERMANOVA, R² = 0.XX, F = X.XX, p < 0.05)，解释了XX%的群落变异"
