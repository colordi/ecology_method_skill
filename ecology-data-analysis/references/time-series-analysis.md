# 时间序列分析指南

本文档提供生态学中常见的时间序列分析方法，特别关注物候期分析和预测。

## 物候期分析

### 物候期指标定义

**始发期（Initial Occurrence）**
- 定义：某一生物学事件首次发生的日期
- 计算方法：时间序列中首次观测到目标事件的日期
- 示例：首次捕获到成虫、首次开花、首次展叶

**高峰期（Peak Period）**
- 定义：某一生物学指标达到最大值或特定阈值的日期
- 常用阈值：累积量达到总量的50%
- 示例：种群数量峰值日期、开花高峰期

### 物候期数据处理

```r
# 计算始发期
initial_date <- data %>%
  filter(观测值 > 0) %>%
  group_by(年份, 分组变量) %>%
  summarise(始发期 = min(日期))

# 计算高峰期（累积50%）
peak_date <- data %>%
  arrange(年份, 分组变量, 日期) %>%
  group_by(年份, 分组变量) %>%
  mutate(
    累积量 = cumsum(观测值),
    累积比例 = 累积量 / sum(观测值)
  ) %>%
  filter(累积比例 >= 0.5) %>%
  slice(1) %>%
  select(年份, 分组变量, 高峰期 = 日期)
```

## 时间序列预测模型

### 基于环境因子的预测

**积温模型**
- 原理：生物发育与温度累积相关
- 适用：物候期预测、发育进度预测
- R包：自定义计算或使用 `phenModel`

**线性回归模型**
```r
# 简单线性回归
model <- lm(物候期 ~ 累积积温, data = phenology_data)

# 多元线性回归
model <- lm(物候期 ~ 累积积温 + 降水量 + 纬度, data = phenology_data)
```

**广义线性模型（GLM）**
- 适用于非正态分布的响应变量
- 常用分布：Gamma（连续正值）、Poisson（计数）

### 机器学习方法

**随机森林**
- 优点：处理非线性关系、变量重要性评估
- R包：`randomForest`, `ranger`

**梯度提升树**
- 优点：预测精度高、可解释性较好
- R包：`xgboost`, `gbm`

## 模型验证策略

### 时间序列交叉验证

**留一年验证**
- 使用 n-1 年数据训练，预测第 n 年
- 适用于年际预测

**滚动窗口验证**
- 使用前 k 年数据训练，预测第 k+1 年
- 逐年滚动验证

### 评估指标

- **RMSE**（均方根误差）：预测误差的标准差
- **MAE**（平均绝对误差）：预测误差的平均值
- **R²**：模型解释的变异比例
- **预测偏差**：系统性高估或低估

## 常见问题

### 数据不足
- 问题：年份数据少（<5年）
- 解决：使用简单模型、增加空间重复、文献数据补充

### 非线性关系
- 问题：环境因子与物候期呈非线性关系
- 解决：使用 GAM、机器学习方法

### 年际变异大
- 问题：不同年份物候期波动大
- 解决：纳入更多环境因子、考虑滞后效应
