# 内容生成指南

报告的主要受众是**非技术背景的领导和决策者**，内容应注重可读性和可理解性。

## 分析章节结构

每个分析章节应包含以下7个部分：

### 1. 方法背景与定义（约200-300字）

- 用通俗语言定义该方法是什么，解决什么问题
- 简要介绍方法的发展历史和在生态学中的应用
- 用类比或例子帮助非技术人员理解核心思想

**示例**："方差分析就像比较不同班级的考试成绩，看看班级之间的差异是否超出了学生个体差异的范围"

### 2. 为什么选择这个方法（约150-200字）

- 说明该方法如何与研究问题匹配
- 解释为什么该方法适合当前的数据特征
- 列出该方法的优势（2-3点）
- 诚实说明该方法的局限性

**示例**："我们选择NMDS而不是PCA，因为我们的物种数据不满足线性关系假设"

### 3. 方法的前提假设（约100-150字）

- 列出该方法的主要前提假设（2-3个）
- 用通俗语言解释每个假设的含义
- 说明如何检验这些假设
- 报告本研究数据是否满足这些假设

**示例**："正态性假设要求数据呈钟形分布，我们通过Q-Q图检验，发现数据基本满足该假设"

### 4. 关键概念解释（约100-150字）

- 列出并解释该方法涉及的核心术语（3-5个）
- 避免循环定义，用日常语言解释
- 说明每个术语的生态学意义

**示例**："p值就像是'巧合的可能性'，p<0.05意味着这个结果出现的概率小于5%，因此我们认为这不是偶然现象"

### 5. 分析实施

- 提供完整的R代码（代码块默认折叠）
- 在代码块前用文字说明分析步骤（3-5步）
- 每个步骤用通俗语言描述做了什么

### 6. 结果展示

- 提供清晰的图表（使用ggplot2）
- **图表引用规范**：每个图表在正文中必须被引用，使用"如表X所示"、"图X显示"等表述
- **图表解读段落**：每个图表后必须有1-2段文字解读

### 7. 结果解释（约300-400字，最重要）

- **统计学解释**：报告p值、效应量等
- **生态学解释**：从生态学角度解释生物学意义
- **与已有研究的比较**
- **可能的机制**
- **与研究假设的关系**
- **不确定性与局限**

## 重要提醒

不要一次性完成所有分析，必须逐章节进行，每个章节都要经过"执行→讨论→填充→确认"的循环。
