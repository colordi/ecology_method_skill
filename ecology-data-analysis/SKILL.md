# 生态学数据分析

## 概述

本 skill 通过三阶段工作流程指导用户进行生态学数据分析，生成包含 R 代码、统计结果和生态学解释的专业 Quarto 报告。

## 工作流程

分析遵循三个连续阶段：

1. **意图对齐**：通过针对性问题识别研究问题和数据特征
2. **结构冻结**：创建详细的 Quarto 格式分析大纲
3. **渐进式分析**：执行分析并将结果填入报告

### 阶段 1：意图对齐

**目标**：通过高信息密度的问题快速理解用户的数据和研究目标。

**流程**：
1. 阅读 `references/intent-questions.md` 获取提问框架
2. 针对以下方面提出问题：
   - 数据类型和结构
   - 研究设计
   - 研究目标
   - 变量及其测量尺度
3. 使用 `references/analysis-methods.md` 识别合适的分析方法

### 阶段 2：结构冻结

**目标**：创建全面的分析大纲以避免上下文长度限制。

**流程**：
1. 复制 `assets/analysis_report_template.qmd` 作为起点
2. 根据阶段 1 的发现定制模板：
   - 更新标题、作者和数据来源信息
   - 添加阶段 1 中识别的具体分析方法章节
   - 每个分析章节应包含：方法说明、代码块、结果和解释占位符
3. 将定制的大纲保存为用户工作目录中的 .qmd 文件

### 阶段 3：渐进式分析

**目标**：逐步执行分析并将结果填入 Quarto 报告。

**关键原则**：边分析边填充，每完成一个章节后与用户讨论并确认，再进行下一步。

**流程**：
1. 按顺序处理大纲中的每个分析章节
2. 对于每个分析章节：
   - 使用 tidyverse 编写数据处理的 R 代码
   - 使用适当的包（主要是 vegan）执行分析
   - 使用 ggplot2 生成可视化图表
   - 使用 `references/interpretation-guide.md` 解释结果
   - **暂停并与用户讨论**：展示分析结果，询问用户是否满意
   - **填充到 .qmd 文件**：确认无误后，将代码、结果和解释填入相应章节
   - **确认后再继续**：等待用户确认后再进行下一个章节
3. 确保所有结果都包含统计显著性和生态学意义

**重要提醒**：不要一次性完成所有分析，必须逐章节进行，每个章节都要经过"执行→讨论→填充→确认"的循环。

## 资源

本 skill 包含支持分析工作流程的捆绑资源：

### references/
- `intent-questions.md`：阶段 1 意图对齐的提问框架
- `analysis-methods.md`：选择合适分析方法的决策树
- `interpretation-guide.md`：解释统计结果和生态学意义的指南
- `r-packages.md`：生态学分析推荐的 R 包
- `time-series-analysis.md`：时间序列分析方法指南，包括物候期分析和预测模型

### assets/
- `analysis_report_template.qmd`：预设数据概况、数据清洗和分析方法章节的 Quarto 报告模板
